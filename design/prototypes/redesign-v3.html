间距与栅格

  • 页面内边距 26 / 30（原 16/24 混用），阅读型页面居中限宽 860 / 1080
  • 区块纵向节奏 16 / 20 / 24 三档（原 gap-2.5~6 随意取值）
  • 卡片内边距统一 18/20，紧凑卡 14/16（原 12~20 六种）
  • 卡片圆角改用 var(--radius-xl)：三主题真正差异化 12 / 14 / 10px（原 token 是死代码）
  • 侧边栏 192 → 224px，11 项分 3 组 + active 左指示条
  • 图标统一 16（导航）/ 14（行内）/ 18（统计 tile），描边 1.8

页面级改动

  • 今日概览：7 小卡 → 4 核心大卡 + 右栏「本周速览」合并趋势图与 3 个次级指标；新增「记一笔进展」入口
  • 项目卡：项目色顶条 + 名称 15px + 两行描述 + 进度 + 节点 chip，xl 三列
  • 项目详情·概览：环形进度 Hero + 5 项关键数字 + 最近日志/临近节点双栏
  • 任务筛选：select 平铺 → 状态 chips + 下拉组合工具条
  • 时间节点：新增左侧日期块（星期 + 大日期），倒计时 badge 放大
  • 灵感：左缘状态色条（黄待整理/蓝已整理/绿已转）一眼分区
  • 论文投稿：纯文字流转说明 → 图形化状态链 chips
  • 成果台账：年份大标题 + 时间线圆点 + 类型图标 tile

主题适配策略

  • 全部颜色仍走 原有 6 套 CSS token，零新增色值（purple badge 除外，沿用现有定义）
  • 圆角/字体 token（--radius-* / --font-display）真正接入组件层
  • notion 主题「卡深底浅」的反转关系在原型中可直接验证
  • 深色模式下所有 soft 底色均为主题专属（暖墨/冷灰/中性），不再叠 black/40
