格致 · 科研工作台 — UI 风格改造方案（3 原型）

从 UI-Design-Platform（StyleForge） 收录的 54 套开源设计系统（awesome-design-md）中，按本产品定位—— 单机科研效率工具 · 学术场景 · 长时间盯屏使用 · 中文排版——初选出 3 套气质契合的风格，重做了 首次启动「选择数据目录」页，并在每个原型下半部分附了主界面同风格示意。

预览提示：点击缩略图或在新窗口打开后，路径框 / 主按钮可点击模拟选择目录；主界面示意中的侧边栏导航可切换高亮。原型仅作风格讨论用，不改动现有代码。

方案 A · 源风格 claude

学术编辑风

陶土暖纸画布 + 衬线标题 + Ring 描边。像一本护封考究的学术笔记，「格物致知」的气质最浓：暖色耐看、编辑感强，数字用衬线体呈现报告气质。

纸 #f5f4ed 卡 #faf9f5 陶土 #c96442 墨 #141413 Georgia + 宋体标题

最契合学术身份，阅读型页面（进展日志 / 周报）会非常出彩；代价是深色模式需要定制一套「暖深色」，工作量略大。

方案 B · 源风格 notion

暖中性极简

内容优先、几乎无装饰：大字号排版 + 暖灰面板 + 耳语级边框。研究人员最熟悉的工具气质，信息密度高也不累眼，蓝色仅做功能性点缀。

白 #ffffff 暖灰 #f7f6f3 蓝 #2383e2 墨 #37352f 圆角 6–10px

耐看、零学习成本，灰底卡片体系对表格 / 看板类界面非常友好；个性最弱，与「用 Notion 管科研」的心智重合。

方案 C · 源风格 linear.app

精密高效 SaaS 推荐

任务管理工具的标杆语言：靛紫唯一品牌色 + 细边框白卡 + 多层轻阴影 + 品牌辉光。激活态用「白色药丸」表达，精密、克制、效率感强。

画布 #f7f8f8 卡 #ffffff 靛紫 #5e6ad2 边 #e6e8ef Inter + 紧字距

与现有 indigo 主色（#4f46e5）同族，整体迁移成本最低；Linear 的暗色体系成熟，现有深色模式可平滑对齐；看板 / 任务 / 日历等效率组件表现最佳。

如何预览

  1. 双击打开本目录下的三个 onboarding-*.html（或点击上方卡片缩略图），每个页面上半屏即重设计的首次启动页。
  2. 点击路径框或主按钮 → 模拟选中 F:\Nutstore\1\格致科研工作台，按钮变为「开始使用」。
  3. 向下滚动查看主界面同风格示意（侧边栏导航可点击切换）。

落地成本说明：本项目样式已语义化为 CSS 变量（src/renderer/src/styles.css 的 :root / .dark / @theme inline）， 全部组件通过 bg-surface、text-text-2、border-border 等语义类取色。 因此确定方向后，第一步只需替换变量值 + 字体栈即可让全应用换肤，第二步再精修 Onboarding 页结构、圆角与阴影细节（ui.tsx 组件级微调）。
